Cross-tab persistence

Open this page in two tabs. The store is persisted, so every write saves the whole state to localStorage.

What to check

  1. Bump left in tab A. Tab B updates without a reload.
  2. Now the real case: bump left in tab A, then bump right in tab B. Both counts must survive. Before this fix tab B wrote its stale copy and tab A's increment vanished.
  3. Type a note in one tab — it appears in the other.
  4. Reset in one tab clears both.
  5. No infinite ping-pong: counts settle immediately and the console stays quiet.
